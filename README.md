# pairwise-cooldown-charge

技能冷却在充能类技能上越用越快：冷却按真实时间累加，暂停和慢动作没有缩放；充能层数用整数计数，最后一层充能到一半时被四舍五入成整层；冷却缩减属性叠乘而不是相加，叠满后接近零冷却；技能释放失败时冷却已经开始，玩家空放也进入冷却；多段技能的每一段共用同一个冷却键，第二段把第一段重置；充能恢复事件在帧末统一派发，同一帧多次恢复只触发一次；服务器和客户端各自计时，网络延迟下客户端先亮；冷却在角色死亡后继续走，复活瞬间全技能可用；切换武器时冷却表没有按武器隔离，共享冷却串台；批量更新时没有统一时间步，低帧率下冷却跳变。gameplay/cooldown_charge.py 是核心，tests/test_cooldown_charge.py 15个红。要修的是：时间缩放；充能浮点累计；缩减加法上限；失败回滚；多段独立键；逐次恢复事件；服务器权威；死亡暂停；按武器隔离；统一时间步。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
